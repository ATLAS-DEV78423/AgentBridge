# Phase 3-6 Build Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete OpenCode/Kilo scanners, normalization, capability registry, compatibility rules, target writers, diff command, and transaction safety.

**Architecture:** Scanner adapters produce AgentBundle → Normalizer converts to canonical resources → Capability registry defines what each agent supports → Compatibility rules map capabilities → Target writers generate files → Transaction engine applies with backup/rollback.

**Tech Stack:** TypeScript, Node.js 18+, Vitest, native fs/path/crypto

**Spec:** refeernces ,plans and agent.md/agent-migration-user-ready-roadmap.md

## Global Constraints
- TypeScript strict mode
- Node.js LTS (18+)
- TDD mandatory for non-trivial logic
- No new dependencies
- Fewest files possible
- YAGNI: question every abstraction
